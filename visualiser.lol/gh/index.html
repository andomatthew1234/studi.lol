To use features like GitHub repositories, gists, and even live websites, sign in with your GitHub account. Don't worry, it will only take 30 seconds.

Setup GitHub Access

Follow these steps to generate a Personal Access Token.

Step 1: Go to the website

Select the button below to open the GitHub tokens page.

Open GitHub Settings
You may need to re-sign into GitHub for security reasons.

Step 2: Give it a name

Make sure you enter a name for the PAT in the Note field so you remember what it's for.

Step 3: Add permissions

Check the boxes for the following permissions:

  • repo
  • write:packages
  • gist
  • user
  • project
  • delete_repo
Functions will not work as expected if you do not add these permissions. Or, as shown highlighted in the red circle in the example below.

Step 4: Press create

Scroll to the bottom and select the big green button to create your PAT!

Step 5: Copy your PAT!

Press the Copy button on GitHub and paste your PAT in here.
